# Phase 15 Plan 02: Tier Enforcement + iOS 402 Handling

## Goal

Server-side limits enforced for all three billing-controlled resources.
iOS surfaces a clear upgrade prompt on 402 rather than a generic error.

## Context

From 15-01:
- `coaches` row has `athlete_limit`, `device_limit`, `monthly_session_limit` (None = unlimited)
- `_TIER_LIMITS` dict + `_get_coach_row()` helper already in `api.py`
- Free: 3 athletes / 1 device / 20 sessions/month
- Paid (starter/enterprise): limits per `_TIER_LIMITS`; `monthly_session_limit=None` = skip check

iOS:
- `RecordScreen.js` uploads via `FileSystem.uploadAsync` → check `result.status` → currently a generic throw on non-2xx
- `AthletesScreen.js` creates athletes directly via `supabase.from('athletes').insert(...)` → must proxy through API

coaches table has `team_id`; athletes table has `team_id` + `coach_id` columns.

### Task 2 — `api.py`: Enforce limits in `/process`

**Action:** Inside the `if athlete_id:` / `if not sb_admin: ... else:` block in `process_session`,
replace the inline coach_id fetch with `_get_coach_row()` that also pulls limit columns.
Then check:

2. Device limit (skip if `device_limit is None`; only check when `device_id` is a new device)

Place these checks BEFORE the storage upload so no CSV is uploaded for over-limit sessions.
Raise `HTTPException(status_code=402, detail="...")` on breach.

**Change summary** in `process_session` inside the `else:` branch (after `timestamp = int(time.time())`):

```python
# ── Coach row + limit checks ─────────────────────────────────────────
import datetime as _dt
coach = _get_coach_row(
    sb_admin, request.state.user_id,
    "id, device_limit, monthly_session_limit"
)
coach_row_id = coach["id"] if coach else None

if coach:
    # Monthly session limit
    if coach.get("monthly_session_limit") is not None:
        _now = _dt.datetime.utcnow()
        _month_start = _now.replace(day=1, hour=0, minute=0, second=0, microsecond=0).isoformat()
        try:
            _sr = sb_admin.table("sessions").select("id", count="exact") \
                .eq("coach_id", coach_row_id).gte("created_at", _month_start).execute()
            _session_count = _sr.count or 0
        except Exception:
            _session_count = 0
        if _session_count >= coach["monthly_session_limit"]:
            raise HTTPException(
                status_code=402,
                detail=f"Monthly session limit reached ({coach['monthly_session_limit']} sessions). "
                       "Upgrade your plan to record more.",
            )

    # Device limit (only when presenting a new device)
    if device_id and coach.get("device_limit") is not None:
        try:
            _ex = sb_admin.table("devices").select("chip_id") \
                .eq("chip_id", device_id).eq("coach_id", coach_row_id).execute()
            _is_new_device = not (_ex.data and len(_ex.data) > 0)
        except Exception:
            _is_new_device = False
        if _is_new_device:
            try:
                _dr = sb_admin.table("devices").select("chip_id", count="exact") \
                    .eq("coach_id", coach_row_id).execute()
                _device_count = _dr.count or 0
            except Exception:
                _device_count = 0
            if _device_count >= coach["device_limit"]:
                raise HTTPException(
                    status_code=402,
                    detail=f"Device limit reached ({coach['device_limit']} device(s)). "
                           "Upgrade your plan to register more devices.",
                )
```

### Task 3 — `api.py`: Add `POST /athletes` endpoint

**Action:** Add endpoint after `GET /devices`. Fetches coach row with `id, team_id, athlete_limit`;
counts existing athletes; enforces limit; inserts via admin client (bypasses RLS);
returns inserted row.

```python
@app.post("/athletes")
async def create_athlete(request: Request, _auth=Depends(require_auth)):
    sb_admin = _get_supabase_admin()
    if not sb_admin:
        raise HTTPException(status_code=503, detail="Storage not configured")
    try:
        body = await request.json()
    except Exception:
        raise HTTPException(status_code=400, detail="Invalid JSON body")
    name = (body.get("name") or "").strip()
    if not name:
        raise HTTPException(status_code=400, detail="name is required")

    coach = _get_coach_row(sb_admin, request.state.user_id, "id, team_id, athlete_limit")
    if not coach:
        raise HTTPException(status_code=403, detail="Coach profile not found")

    coach_id = coach["id"]
    athlete_limit = coach.get("athlete_limit")
    if athlete_limit is not None:
        try:
            r = sb_admin.table("athletes").select("id", count="exact") \
                .eq("coach_id", coach_id).execute()
            count = r.count or 0
        except Exception:
            count = 0
        if count >= athlete_limit:
            raise HTTPException(
                status_code=402,
                detail=f"Athlete limit reached ({athlete_limit} athletes). "
                       "Upgrade your plan to add more.",
            )

    hw = body.get("head_waist_m")
    stroke_type = (body.get("stroke_type") or "breaststroke")
    try:
        resp = (
            sb_admin.table("athletes")
            .insert({
                "team_id":     coach["team_id"],
                "coach_id":    coach_id,
                "name":        name,
                "stroke_type": stroke_type,
                "head_waist_m": hw,
            })
            .select("id, name, stroke_type, head_waist_m")
            .single()
            .execute()
        )
        return resp.data
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))
```

```js
  const handleAdd = async () => {
    if (!newName.trim()) return;
    setSaving(true);
    const hw = newHW.trim() !== '' ? parseFloat(newHW) : null;
    try {
      const resp = await fetch(`${API_BASE}/athletes`, {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
          Authorization: `Bearer ${session?.access_token}`,
        },
        body: JSON.stringify({ name: newName.trim(), stroke_type: 'breaststroke', head_waist_m: hw }),
      });
      if (resp.status === 402) {
        const body = await resp.json().catch(() => ({}));
        Alert.alert(
          'Athlete Limit Reached',
          (body.detail || 'You have reached your athlete limit.') + '\n\nVisit swimnetics.com to upgrade.',
          [{ text: 'OK' }],
        );
        setSaving(false);
        return;
      }
      if (!resp.ok) {
        const body = await resp.json().catch(() => ({}));
        Alert.alert('Error', body.detail || 'Failed to add athlete.');
        setSaving(false);
        return;
      }
      const inserted = await resp.json();
      setAthletes(prev =>
        [...prev, inserted].sort((a, b) => a.name.localeCompare(b.name))
      );
      setNewName('');
      setNewHW('');
      setAdding(false);
    } catch (e) {
      Alert.alert('Error', e.message || 'Failed to add athlete.');
    } finally {
      setSaving(false);
    }
  };
```

- `datetime` is already imported in `billing_status`; use `import datetime as _dt` locally in the check to avoid module-level side effects (or move `import datetime` to top-level — either way is fine)
- `_get_coach_row()` is defined below `/process` in the file; Python resolves at call time so order doesn't matter

- Free-tier coaches: athlete_limit=3, device_limit=1, monthly_session_limit=20 (all non-None → all enforced)
- Paid tiers: monthly_session_limit=None → session check skipped
