<objective>
## Goal
Add a Device Management screen to the iOS app: coaches can see their registered encoder(s), view stats (firmware version, last active, session count), rename inline, and deregister a device. Backed by two new API capabilities on the existing /devices endpoints.

## Purpose
Coaches need to know which device is in use and trust the hardware metadata. Phase 14 auto-registers devices and supports rename/list — this phase surfaces that in the UI and adds delete.

## Output
- `api.py`: GET /devices enriched with `session_count`; new DELETE /devices/{chip_id}
- `DevicesScreen.js`: new iOS screen (dark-themed, consistent with app)
- `AthletesScreen.js`: gear icon in header → navigates to Devices
- `App.js`: Devices stack route registered
</objective>


## AC-2: DELETE /devices/{chip_id} deregisters device
```gherkin
Given a coach owns a device with a given chip_id
When DELETE /devices/{chip_id} is called with a valid Bearer JWT
Then the device row is removed from the devices table
  and 200 {"ok": true} is returned
  and a 403 is returned if the chip_id belongs to a different coach
```

```gherkin

     last_seen_at formatted as "MMM D, YYYY", and session_count

When the coach taps the device name

Given a device card
```
