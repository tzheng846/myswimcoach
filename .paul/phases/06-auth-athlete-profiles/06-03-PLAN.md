<objective>
## Goal
Add an athlete roster screen, require the coach to select an athlete before recording, save each completed session to Supabase, and flip FastAPI `/process` from optional to required auth.

## Purpose
Without athlete selection, all sessions are anonymous — no way to track a swimmer's progress over time, which is the core value of the product. This plan completes the data-capture loop: coach logs in → selects athlete → records → metrics saved against that athlete.

## Output
- `AthletesScreen.js` — list team athletes from Supabase, add new athlete inline
- `App.js` — AppStack starts on AthletesScreen; RecordScreen accessible via athlete tap
- `AuthContext.js` — exposes `teamId` and `coachId` (fetched from `coaches` table on login)
- `RecordScreen.js` — receives `athleteId`/`athleteName`/`strokeType` via route params; inserts `sessions` row after successful upload
- `api.py` — `/process` now requires a valid Bearer token (401 if missing)
</objective>

    Rename `optional_auth` to `require_auth` and make a missing/invalid token raise 401:
    ```python
    def require_auth(request: Request):
        auth_header = request.headers.get("Authorization", "")
        if not auth_header.startswith("Bearer "):
            raise HTTPException(status_code=401, detail="Authentication required")
        token = auth_header[7:].strip()
        sb = _get_supabase()
        if sb is None:
            raise HTTPException(status_code=503, detail="Auth service unavailable")
        try:
            response = sb.auth.get_user(token)
            if not response.user:
                raise HTTPException(status_code=401, detail="Invalid token")
            request.state.user_id = response.user.id
        except HTTPException:
            raise
        except Exception:
            raise HTTPException(status_code=401, detail="Invalid token")
    ```
    Update `/process` signature: `_auth=Depends(require_auth)` (was optional_auth).
    Delete the old `optional_auth` function entirely.
