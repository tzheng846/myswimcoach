## Backend contract (verified in api.py:487 + ratings.py:269)
GET /team/overview (auth Bearer; coach-scoped) →
  { athlete_count, tested_this_week,
    pillars:[{key,label,good,ok,needs_work,unknown}],
    athletes:[{athlete_id,name,stroke_type,last_tested,last_session_id,
               pillars:[{key,label,band,trend,score,provisional}]}],
    recent:[{athlete_id,name,session_id,date,stroke_type}],   // cap 10
    needs_attention:[{athlete_id,name,reasons:[{type,pillar?,days?}]}],
    rating_colors:{good,ok,needs_work} }
POST /coach/chat (auth) body { session_id, messages:[{role,content}], simple? } → { reply, data }
  — session_id REQUIRED; team tools (Phase 33-02) let it answer team-level questions.

## AC-1: Dashboard renders team-health from /team/overview
```gherkin
Given a signed-in coach with a roster
When the Dashboard tab loads
Then it shows pulse counts (swimmers=athlete_count, tested=tested_this_week, flagged=needs_attention length),
  a 2-column needs-attention list of summary cards (name + derived overall score + weakest pillar,
  icon + band color from rating_colors; stale/never_tested shown as a chip instead of a pillar),
  and a recent-activity feed (recent[], relative dates) tappable to ReportCard
And colors come from payload.rating_colors (never hard-coded bands)
And loading + empty (no athletes / no sessions) states are handled without crashing
```

## AC-2: Settings screen
```gherkin
Given the Dashboard
When the coach taps the top-right gear
Then Settings opens (full-screen over tabs) with: editable team name + coach name (persist via
  supabase coaches/teams update), "Manage devices" → Devices, "Diagnostics" → Diagnostics,
  a m/yd Units toggle (persisted), and Sign out (AuthContext.signOut)
```

## AC-3: Ambient AI — bubble + chat sheet + today's-focus
```gherkin
Given the Dashboard
Then a floating bubble sits above the tab bar; tapping it opens a compact chat sheet that calls
  POST /coach/chat (anchored to the most recent team session_id) and shows replies
And an inline "today's focus" card shows a short generated tip, generated at most once per day
  (cached in SecureStore keyed by date+team) — tapping it opens the chat sheet
And when the team has no sessions, the tip card is hidden and the bubble explains there's no data yet
And no console errors; if ANTHROPIC unset the chat surfaces the 503 gracefully (no crash)
```
