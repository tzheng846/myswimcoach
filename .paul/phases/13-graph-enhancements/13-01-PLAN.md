## Goal
Extract the duplicated VelocityChart component into a shared file, add a time-marker vertical line that appears when a distance preset is selected in TimeToX, and add a meters/yards unit toggle that converts all distance and velocity labels.

## Purpose
VelocityChart is copy-pasted in both RecordScreen and ReportCardScreen. Any enhancement would require editing two places. This plan establishes the single shared component so Plans 02 and 03 can build on it without duplication. The time marker gives visual feedback connecting the "Time to Distance" calculation to the graph. The unit toggle serves US-based coaches who think in yards.
