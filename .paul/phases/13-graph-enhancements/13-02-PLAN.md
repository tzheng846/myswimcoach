<objective>
## Goal
Add interactive touch cursor (single-finger drag shows velocity + time at the touched point) and pinch-to-zoom (two-finger pinch scales the time axis) to VelocityChart using React Native's built-in PanResponder — no new dependencies.

## Purpose
Coaches need to inspect specific moments in a swim: "what was the velocity at the 15-second mark?" Currently the chart is read-only. A drag cursor answers this without leaving the screen. Zoom lets them focus on a narrow time window (e.g., just the first 10 strokes) and read the cursor more precisely.

<task type="auto">
  <name>Task 2: Add pinch-to-zoom with double-tap reset</name>
  <files>swimnetics-mobile/src/components/VelocityChart.js</files>
  <action>
    Add zoom state inside VelocityChart (only when interactive):
    ```js
    const [zoomWindow, setZoomWindow] = React.useState(null); // null = full view; {tStart, tEnd}
    const pinchRef = React.useRef(null); // { startDist, startWindow }
    const lastTapRef = React.useRef(0); // timestamp of last tap for double-tap detection
    ```

    Apply zoom window to the data filtering step:
    - When zoomWindow is set: before downsampling, filter indices to those where
      `time[i] >= zoomWindow.tStart && time[i] <= zoomWindow.tEnd`
    - Update tMin/tMax/tRange to use zoomWindow values (so px() maps correctly):
      `const tMin = zoomWindow ? zoomWindow.tStart : t[0]`
      `const tMax = zoomWindow ? zoomWindow.tEnd : t[t.length - 1]`

    Helper:
    ```js
    const getPinchDist = (touches) => {
      const [a, b] = touches;
      return Math.hypot(a.pageX - b.pageX, a.pageY - b.pageY);
    };
    ```

    Update `handleTouch` to handle the two-touch case:
    ```js
    if (touches.length === 2) {
      const dist = getPinchDist(touches);
      if (!pinchRef.current) {
        // Pinch start
        const fullRange = { tStart: t[0], tEnd: t[t.length - 1] };
        pinchRef.current = { startDist: dist, startWindow: zoomWindow ?? fullRange };
      } else {
        // Pinch move: scale the window
        const scale = pinchRef.current.startDist / dist; // >1 = zoom in, <1 = zoom out
        const { tStart, tEnd } = pinchRef.current.startWindow;
        const mid = (tStart + tEnd) / 2;
        const halfRange = ((tEnd - tStart) / 2) * Math.max(0.1, Math.min(1.0, scale));
        const fullTMin = rawT[0], fullTMax = rawT[rawT.length - 1]; // full data range
        const newStart = Math.max(fullTMin, mid - halfRange);
        const newEnd   = Math.min(fullTMax, mid + halfRange);
        if (newEnd - newStart > 0.5) { // minimum 0.5s window
          setZoomWindow({ tStart: newStart, tEnd: newEnd });
        }
      }
      return; // don't set cursor during pinch
    }
    pinchRef.current = null; // reset pinch when single finger
    ```

    Note: `rawT` = the full (non-zoomed) downsampled time array — compute it before applying the zoom filter, or store the full range separately.

    In `onPanResponderRelease`:
    - Reset `pinchRef.current = null`
    - Double-tap detection:
      ```js
      const now = Date.now();
      if (now - lastTapRef.current < 300) {
        setZoomWindow(null); // double-tap resets zoom
        setCursor(null);
      }
      lastTapRef.current = now;
      ```

    Show a "Reset zoom" pill below the chart (outside Svg) when zoomWindow is not null:
    ```jsx
    {interactive && zoomWindow && (
      <TouchableOpacity onPress={() => setZoomWindow(null)} style={styles.resetZoom}>
        <Text style={styles.resetZoomText}>Reset zoom</Text>
      </TouchableOpacity>
    )}
    ```
    Add styles to a local StyleSheet in VelocityChart.js:
    `resetZoom: { alignSelf: 'center', marginTop: 4, paddingHorizontal: 10, paddingVertical: 3, backgroundColor: '#F0F2F5', borderRadius: 10 }`
    `resetZoomText: { fontSize: 11, color: '#7F8C8D' }`

    Import TouchableOpacity and StyleSheet from react-native.

    Also: the marker line (markerTimeS) should only render when markerTimeS is within the current
    tMin..tMax window. Add a guard: `if (markerTimeS != null && markerTimeS >= tMin && markerTimeS <= tMax)`.
  </action>
