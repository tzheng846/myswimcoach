  <name>Task 1: Add _METRIC_RANGES and _rate_metric to app.py</name>

  <action>
    Add after the _STROKE_PALETTE constant:

    ```python
    # Breaststroke metric ranges — (good_range_fn, ok_range_fn, label, ranges_text)
    # Each entry: (key, good_fn, ok_fn, ranges_text)
    # good_fn(v) → True if value is in the Good band
    # ok_fn(v)   → True if value is in the OK band (else Needs work)
    def _rate_metric(key: str, value) -> tuple[str, str]:
        """Return (label, hex_color) for a metric value. Returns ("", "") if unrateable."""
        if value is None or (isinstance(value, float) and np.isnan(value)):
            return "", ""
        r = _METRIC_RANGES.get(key)
        if r is None:
            return "", ""
        good_fn, ok_fn = r["good"], r["ok"]
        if good_fn(value):
            return "Good", "#2d9e5f"
        if ok_fn(value):
            return "OK", "#d4860a"
        return "Needs work", "#c0392b"
    ```

    Add _METRIC_RANGES dict above _rate_metric:

