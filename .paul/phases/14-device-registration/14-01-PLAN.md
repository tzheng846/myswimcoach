<objective>
## Goal
Auto-register ESP32 devices in Supabase when a session is uploaded, expose firmware version via BLE, and add `PATCH /devices/{chip_id}` + `GET /devices` API endpoints so coaches can name and list their devices.

## Purpose
Fills `device_id` on every session row (currently always NULL), giving coaches a way to track which physical device recorded each session — prerequisite for multi-device management and the eventual QR registration flow.

## Output
- `motor_logger_esp32.ino`: `FIRMWARE_VERSION` define + `FW_UUID` read-only BLE characteristic
- `api.py`: `device_id` + `firmware_version` form params in `/process`; devices upsert inside session-save block; `PATCH /devices/{chip_id}`; `GET /devices`
- Supabase: `devices` table + `sessions.device_id` column (applied via manual SQL checkpoint)
</objective>

```sql
-- New devices table
CREATE TABLE IF NOT EXISTS devices (
  chip_id          text PRIMARY KEY,
  name             text NOT NULL DEFAULT '',
  coach_id         uuid REFERENCES coaches(id) ON DELETE SET NULL,
  firmware_version text,
  created_at       timestamptz DEFAULT now(),
  last_seen_at     timestamptz DEFAULT now()
);

-- Enable RLS
ALTER TABLE devices ENABLE ROW LEVEL SECURITY;

-- Coaches can read/update their own devices
CREATE POLICY "Coach owns device" ON devices
  USING (coach_id = (SELECT id FROM coaches WHERE user_id = auth.uid()));

-- Link sessions to devices
ALTER TABLE sessions ADD COLUMN IF NOT EXISTS device_id text REFERENCES devices(chip_id) ON DELETE SET NULL;
```

    **3d. Add `PATCH /devices/{chip_id}` endpoint** after the existing `delete_session` function:
    ```python
    @app.patch("/devices/{chip_id}")
    async def rename_device(chip_id: str, request: Request, _auth=Depends(require_auth)):
        try:
            body = await request.json()
        except Exception:
            raise HTTPException(status_code=400, detail="Invalid JSON body")
        name = body.get("name", "").strip()
        if not name:
            raise HTTPException(status_code=400, detail="name is required")
        sb_admin = _get_supabase_admin()
        if not sb_admin:
            raise HTTPException(status_code=503, detail="Storage not configured")
        coach_row_id = None
        try:
            coach_resp = (
                sb_admin.table("coaches")
                .select("id")
                .eq("user_id", request.state.user_id)
                .single()
                .execute()
            )
            coach_row_id = coach_resp.data["id"] if coach_resp.data else None
        except Exception:
            pass
        if not coach_row_id:
            raise HTTPException(status_code=403, detail="Coach profile not found")
        try:
            sb_admin.table("devices").update({"name": name}).eq("chip_id", chip_id).eq("coach_id", coach_row_id).execute()
        except Exception as e:
            raise HTTPException(status_code=500, detail=str(e))
        return {"ok": True}
    ```

    **3e. Add `GET /devices` endpoint** after `rename_device`:
    ```python
    @app.get("/devices")
    async def list_devices(request: Request, _auth=Depends(require_auth)):
        sb_admin = _get_supabase_admin()
        if not sb_admin:
            raise HTTPException(status_code=503, detail="Storage not configured")
        coach_row_id = None
        try:
            coach_resp = (
                sb_admin.table("coaches")
                .select("id")
                .eq("user_id", request.state.user_id)
                .single()
                .execute()
            )
            coach_row_id = coach_resp.data["id"] if coach_resp.data else None
        except Exception:
            pass
        if not coach_row_id:
            raise HTTPException(status_code=403, detail="Coach profile not found")
        try:
            resp = (
                sb_admin.table("devices")
                .select("chip_id, name, firmware_version, last_seen_at")
                .eq("coach_id", coach_row_id)
                .order("last_seen_at", desc=True)
                .execute()
            )
            return {"devices": resp.data or []}
        except Exception as e:
            raise HTTPException(status_code=500, detail=str(e))
    ```
