<objective>
## Goal
Add four enhancements to ReportCardScreen:
1. **Editable session name** — tap the name in the header to edit inline; saved on blur via PATCH
2. **Star toggle** — ★ button in the header; toggles is_starred via PATCH
3. **Notes section** — editable text area at the bottom of the scroll view; saved on blur via PATCH
4. **Non-breaststroke "Coming Soon"** — when stroke_type ≠ breaststroke, the Start Phase, Session, Efficiency, and Time to Distance sections are replaced by a single "Analytics coming soon" card; the velocity chart always shows

## Purpose
Coaches need to organise and annotate sessions after reviewing them. Inline editing in the report card is the natural place — they've just reviewed the data and want to add context before closing.
</objective>

    if (!authSession?.access_token) return;
    try {
      await fetch(`${API_BASE}/sessions/${sessionId}`, {
        method: 'PATCH',
        headers: {
          Authorization: `Bearer ${authSession.access_token}`,
          'Content-Type': 'application/json',
        },
        body: JSON.stringify(updates),
      });
    } catch {
      // non-fatal — optimistic update already applied
    }
  }
