<objective>
## Goal
On `/app/match`, decode a QR token from each staged clip's early frames (jsQR, client-side, D5),
look up the session with that `recording_token` (supabase-js, RLS), and **pre-fill** that clip's
session picker with a "Matched by QR" badge. Degrades cleanly to manual when there's no QR / no match
/ the column isn't there yet (D4).

## Purpose
Turns the manual batch match into a one-glance confirm for slated over-water clips, without ever
depending on the QR: the coach can still override, and un-slated clips are untouched.

## Output
- jsQR dependency; `decodeQrToken` + token→session lookup on the match page; QR pre-fill + badge.
</objective>

  <action>
    - `import jsQR from "jsqr";` (already installed).
    - Helper `seekTo(video, t)`: promise that sets currentTime and resolves on `seeked` (3 s timeout → false).
    - Helper `decodeQrToken(url)`: offscreen `<video>` on the object URL; on `loadedmetadata`, sample a
      handful of early stamps (~0.3–4.5 s, capped at duration — the coach films the slate at the start),
      draw each to a canvas (≤640 px wide, `getContext("2d",{willReadFrequently:true})`), run
      `jsQR(imageData.data, w, h, {inversionAttempts:"dontInvert"})`, return the FIRST hit's `.data.trim()`
      or null. ~12 s overall timeout; never throws (resolves null on any failure).
    - Helper `lookupSessionByToken(token)`: `supabase.from("sessions").select("id, created_at, name,
      stroke_type, athlete_id, video_path").eq("recording_token", token).limit(1)`; return `data?.[0] ?? null`;
      on ANY error (e.g. column missing pre-patch) return null — never throw (AC-2).
    - Staged clip gets `qrStatus: "scanning"`, `qrToken: null`, `qrSession: null`. In `handleFiles`, after
      kicking off `grabThumb`, also run `decodeQrToken(clip.url)`: if a token decodes and `lookupSessionByToken`
      finds a session `s`, `patchClip(clip.id, (c) => ({ qrToken, qrSession: s, qrStatus: "matched",
      sessionId: c.sessionId || s.id }))` (⚠ only auto-fill when the coach hasn't already picked); else set
      `qrStatus: "none"`.
    - Picker options: prepend `clip.qrSession` when present and not already in `pickerSessions` (so a
      QR-matched session is selectable even if the athlete filter would hide it), deduped.
    - Badge: when `qrStatus === "matched"`, show a small "✓ Matched by QR" line above the select. "scanning"
      may show a subtle "Scanning for QR…"; "none" shows nothing (most clips have no slate — stay quiet).
    Avoid: blocking staging/thumbnails on decode; throwing when the column is absent; locking the selection
    (must stay overridable); any server-side decode.
