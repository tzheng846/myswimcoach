<objective>
## Goal
Produce a single cross-system **demo-readiness runbook** (`DEMO-READINESS.md` at repo root):
(A) a complete failure-mode catalog across hardware + BLE + app + backend, each with the
coach-visible symptom, root cause, the mitigation already in code, residual risk, and the manual
workaround; and (B) an ordered, checkbox **pre-demo checklist** of app *and* hardware checks the
operator runs before a live coach demo, plus a "if it fails mid-demo, do X" fallback table.

## Purpose
The product is now hardened (Phase 42 failsafes, Phase 34 diagnostics), but a live demo in front
of a coach has its own failure surface — dead battery, BT off, Railway cold-start, no seeded
athlete, loose magnet. A demo that dies on a preventable issue costs a sale. This is the
single sheet the operator runs through beforehand, and the catalog behind it documents exactly
what can go wrong and what the system already does about it.

## Output
`DEMO-READINESS.md` — Part A (failure-mode catalog), Part B (pre-demo checklist), Part C
(mid-demo fallback table). Documentation only; no code/firmware changes.
</objective>
