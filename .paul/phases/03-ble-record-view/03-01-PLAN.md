<objective>
## Goal
Add a "Record" mode to the Streamlit dashboard that lets users connect to the ESP32 SwimLogger via BLE, record a swim session, auto-run the post-processing pipeline, and immediately view the results — all without leaving the browser.

## Purpose
The app currently only displays pre-processed sessions from disk. Athletes need end-to-end functionality: connect hardware → record → analyze in one flow.

## Output
- `app.py` extended with a third radio option ("Record") and a full BLE state-machine UI
- New helper functions: `_ble_scan`, `_recording_thread`, `_run_pipeline`, `_record_view`
- Module-level `_rec_status` dict for thread→UI communication
- After each recording: `raw/swim_<label>_<ts>.csv` (permanent) + `processed/swim_<label>_<ts>.csv` (derived artifact, also kept)
</objective>

    At the top of app.py, after the existing imports, add:
    ```python
    import threading
    import time

    from datetime import datetime

    import vel_acc_extraction

    _rec_status: dict = {"samples": 0, "done": False, "error": None}
    ```

    Before the `main()` function, add three helper functions:

    **`_ble_scan(timeout_s=5.0) -> list[dict]`**
    - Import asyncio + BleakScanner inside the function
    - `asyncio.run(BleakScanner.discover(timeout=timeout_s))` — blocks on main thread, safe because Streamlit has no running event loop
    - Return `[{"name": d.name, "address": d.address} for d in devices if d.name]`

    **`_recording_thread(address, raw_path, stop_event)`**
    - `loop = asyncio.new_event_loop(); asyncio.set_event_loop(loop)` — own event loop, no conflict with Streamlit
    - `async with BleakClient(address) as client:` inside `loop.run_until_complete(_run())`
    - Open raw_path CSV file, write header `["timestamp_us", "angle_counts", "magnet_ok"]`
    - `await client.start_notify("6E400003-B5A3-F393-E0A9-E50E24DCCA9E", on_data)`
    - `on_data` callback: validate `len(data) == 14`; `struct.unpack_from("<IHB", bytes(data), offset)` for each of 2 samples; write row; `_rec_status["samples"] += 2`
    - Poll loop: `while not stop_event.is_set(): if not client.is_connected: _rec_status["error"] = "BLE disconnected"; break; await asyncio.sleep(0.2)`
    - `finally`: `_rec_status["done"] = True`
    - On exception: `_rec_status["error"] = f"BLE error: {exc}"`

    **`_run_pipeline(raw_path, processed_path)`**
    - `vel_acc_extraction.EXCLUDED_SEGMENTS = []`
    - `with unittest.mock.patch.object(webbrowser, "open", lambda *a, **kw: None): vel_acc_extraction.process_file(raw_path, processed_path, target_fs_hz=100.0)`

    Avoid: touching any existing function or import.


    **Step C — `_record_view()` function (insert before `main()`):**

    Init guard at top:
    ```python
    if "ble_state" not in st.session_state:
        st.session_state.ble_state      = "idle"
        st.session_state.ble_discovered = []
        st.session_state.ble_selected   = None
        st.session_state.ble_stop_event = None
        st.session_state.ble_raw_path   = None
        st.session_state.ble_label      = ""
        st.session_state.ble_start_time = None
    ```

    State machine — one `if/elif` block per state:

    **`"idle"`:** `st.info(...)` + "Scan for devices" primary button → set state `"scanning"` + `st.rerun()`

    **`"scanning"`:** `with st.spinner("Scanning for BLE devices (5 s)..."): results = _ble_scan()` → store in `ble_discovered`, set state `"scan_done"` + `st.rerun()`

    **`"scan_done"`:** if empty → `st.warning` + "Scan again" button; else `st.success(f"Found {len(devices)} device(s)")` + selectbox of `"name (address)"` strings + "Connect" + "Scan again" buttons

    **`"connecting"`:** `with st.spinner(...)`: `asyncio.run(async with BleakClient(address): return client.is_connected)` — on success set state `"connected"`; on exception `st.error` + set state `"scan_done"`. Reset `_rec_status` fields here. `st.rerun()`

    **`"connected"`:** `st.success("Connected to <address>")` + `st.text_input("Session label (required)", ...)` + "Start Recording" button (`disabled=not bool(label.strip())`). On click: build `raw_path = f"raw/swim_{label.strip()}_{datetime.now():%Y%m%d_%H%M%S}.csv"`, `Path("raw").mkdir(...)`, reset `_rec_status`, create `threading.Event` stop_event, start `threading.Thread(target=_recording_thread, args=(...), daemon=True)`, set state `"recording"` + `st.rerun()`. Also "Disconnect" button → state `"idle"`.

    **`"recording"`:** Check `_rec_status["error"]` first → if set, `st.error(...)` + state `"connected"` + `st.rerun()`. Check `_rec_status["done"]` → state `"processing"` + `st.rerun()`. Otherwise: `st.warning("Recording in progress...")`, 3-col metrics (Samples, Elapsed `M:SS`, Hz estimate), "Stop Recording" primary button. On stop: `stop_event.set()`, wait up to 2 s for `_rec_status["done"]`, state `"processing"` + `st.rerun()`. At bottom: `time.sleep(1); st.rerun()` for auto-refresh.

    **`"processing"`:** `with st.spinner("Processing recording..."): _run_pipeline(raw_path, proc_path)` — on exception `st.error` + state `"connected"` + `st.rerun()`. On success: `st.session_state.current_file = proc_path`, `st.session_state.mode = "Simple"`, pop slider keys (`time_range`, `cycle_range`, `t_min`, `t_max`, `n_cycles`, `cycle_boundaries`), state `"done"` + `st.rerun()`.

    **`"done"`:** Reset state `"idle"` + `st.rerun()` (transient; next rerun lands in Simple view).

    Avoid: modifying any existing state keys or functions. The `compare_mode` sidebar still renders but is inert while in Record mode.
