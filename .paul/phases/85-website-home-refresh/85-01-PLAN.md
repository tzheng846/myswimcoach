<objective>

## Goal
Rebuild the marketing home page to match the approved mockup
`scratch/website-home-mockup.html`: the Swimnetics mark enters the site for the first time, the page
is reorganised around the race-phase report card, and every word of copy is rewritten so it does not
read as machine-written.

## Purpose
The marketing site has not been touched since `17086cb` (2026-06-22, Phase 40). Ten weeks of product
work is invisible to a visiting coach: the race-phase report card, the within-athlete usual-range
comparison, per-cycle and per-kick trace bands, the cycle overlay, synced multi-camera video. The
page still sells the Phase-8 product as a flat six-card grid of stroke rate, DPS and fatigue index.

## Output
- Mark in the nav lockup, the footer lockup, and as the favicon
- Home page rebuilt as: hero → report card (whole-lap chart + three radars) → usual range → cycle
  pack → video → device → how it works → quote
- `Features.js` and `SampleChart.js` retired
- A build-time-baked geometry module so the public page renders real trace shapes with **no**
  Supabase call
- Copy hygiene enforced by a repo check, not by eye

</objective>
