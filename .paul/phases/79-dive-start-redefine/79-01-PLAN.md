<objective>
## Goal
Redefine `dive_start_s` from **motion-onset** (`baseline_end`, which fires early on the
jump-and-sink artifact) to **the first local minimum immediately left of the first upward
crossing of X m/s** — the FOOT of the launch surge. Fall back to `baseline_end` when nothing
crosses X. Tune X against the human `dive_start_s` marks.

## Purpose
`dive_start_s` opens the race-Start phase. Today it keys on a low velocity floor, so the tug as
the swimmer leaves the block and sinks trips it early (PIPELINE §3 known defect). The coach's
rule (2026-08-20, refined 2026-08-21): find the first surge that clears a real speed X — the tug
never does, a dive/push-off does — then anchor the marker at the LOW point just before that
surge, not its crest. That places Start at the true launch foot.

## Output
- `metrics.detect_dive_start(t, vel, threshold)` — pure, trace-based, returns a full-trace index
  or None.
- `dive_start_s` resolved from it in `resolve_boundaries`; `build_seed` reads it back for the
  annotate draft (mirroring the 75-02 underwater_start precedent).
- `tools/score_dive_start.py` — the X sweep vs ground truth (reproducible claim).
- Chosen X + before/after MAE in 79-01-SUMMARY.md.
</objective>

## Decisions locked (user, 2026-08-21)
- MARKER = `dive_start_s` boundary (the "second peak" wording was informal; today it is
  motion-onset, not any peak).
- RULE = first local minimum on the LEFT of the first upward crossing of X (foot of surge);
  the value there should be relatively LOW. NOT the crest, NOT the raw crossing.
- FALLBACK when no sample crosses X → keep `baseline_end` (source stays "auto"). Never worse
  than today; the new rule only overrides where a real ≥X surge exists.
- X ≈ 2 m/s is a starting guess — SWEEP it against the human marks and pick.
