## Sync math
video_origin_s = (sessionStartPhoneMs − videoStartPhoneMs) / 1000
- sessionStartPhoneMs: shown on RecordScreen results ("Session start (phone clock): <ISO>") and in app console logs
- videoStartPhoneMs: video file creation_time via ffprobe (QuickTime metadata = recording START on iPhone; cross-check against the LED in frame regardless)
</context>
