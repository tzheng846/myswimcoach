<objective>
## Goal
Create a shared BLE context that persists connection state across navigation, and add a "Pair New Device" scan flow to DevicesScreen. After this plan, the app retains knowledge of a BLE connection when navigating away from RecordScreen, and coaches can scan + store a device once in the Devices area instead of rescanning every session.

## Purpose
Currently BLE state lives inside RecordScreen as local component state. Every navigation away unmounts the component, wiping `deviceRef` and `bleState`. This forces rescanning every session. Moving BLE into a React Context makes it survive navigation stack changes and app backgrounding.

## Output
- `src/context/BleContext.js` — new file: BleManager singleton, connection state, AsyncStorage-backed known-devices list
- `App.js` — wrapped with BleProvider
- `DevicesScreen.js` — "Pair New Device" section added at top; pairing stores device to AsyncStorage via context
</objective>

<task type="auto">
  <name>Task 1: Create BleContext.js</name>
  <files>swimnetics-mobile/src/context/BleContext.js</files>
  <action>
    Create a new file at `src/context/BleContext.js`. This is the shared BLE state layer.

    **BleManager singleton:**
    - Create `const manager = new BleManager()` ONCE at module level (outside the component),
      same as RecordScreen.js currently does. This avoids multiple native BLE stacks.

    **State in BleProvider:**
    - `connectedDevice` (state, null or BLE Device object)
    - `connectionStatus` (state): 'disconnected' | 'connecting' | 'connected'
    - `knownDevices` (state): array of `{bleId, name, chipId}` — loaded from AsyncStorage on mount
    - `disconnectListenerRef` (ref): subscription to device.onDisconnected

    **AsyncStorage key:** `'swimnetics_known_devices'`

    **Load known devices on mount:**
    ```js
    useEffect(() => {
      AsyncStorage.getItem('swimnetics_known_devices').then(json => {
        if (json) setKnownDevices(JSON.parse(json));
      });
    }, []);
    ```

    **AppState listener (foreground check):**
    ```js
    useEffect(() => {
      const sub = AppState.addEventListener('change', async (next) => {
        if (next === 'active' && connectedDevice) {
          const still = await connectedDevice.isConnected().catch(() => false);
          if (!still) {
            disconnectListenerRef.current?.remove();
            disconnectListenerRef.current = null;
            setConnectedDevice(null);
            setConnectionStatus('disconnected');
          }
        }
      });
      return () => sub.remove();
    }, [connectedDevice]);
    ```

    **connectToDevice(bleId) method:**
    1. Set connectionStatus → 'connecting'
    2. `manager.connectToDevice(bleId)` → `device.discoverAllServicesAndCharacteristics()`
    3. Derive chipId: `device.name?.replace('SwimLogger-', '') ?? null`
       (firmware names devices "SwimLogger-XXXXXX" where XXXXXX is the 6-char chip ID)
    4. Save to knownDevices if not already there:
       update state + AsyncStorage.setItem
    5. Register `device.onDisconnected` → clears connectedDevice + sets status 'disconnected'
    6. Set connectedDevice + connectionStatus → 'connected'
    7. Return the device object
    8. On any error: set status → 'disconnected', rethrow

    **forgetDevice(bleId) method:**
    - Remove from knownDevices state + update AsyncStorage

    **disconnect() method:**
    - Cancel connection, clear connectedDevice + status

    **Export:**
    - `export function BleProvider({ children })`
    - `export const useBle = () => useContext(BleContext)`
    - Do NOT export `manager` directly — keep it module-level private

    **Dependency:** `@react-native-async-storage/async-storage` — check if already installed.
    If not, the plan assumes it's available (Expo managed workflow ships it).
    Import as: `import AsyncStorage from '@react-native-async-storage/async-storage';`
  </action>
