## AC-1: Four per-cycle panels, no table
```gherkin
Given a session with cycles, viewed in Advanced mode
When the per-cycle breakdown renders
Then four panels appear — distance per stroke, coast, cycle duration, arm peak velocity
And each carries a caption naming the mean or CV it summarizes
And no per-cycle numeric table is rendered anywhere
```

## AC-2: The mean-line caption tells the truth for BOTH session vintages
```gherkin
Given a session whose stored cycles still carry a "phase" key (computed before 61-01)
When its charts render
Then the caption warns that means exclude some cycles, so the line may sit off the dots' average
Given a session with no "phase" key on its cycles (computed after 61-01)
Then that caveat is absent, because the mean IS the average of the plotted dots
```

## AC-3: Data Quality reduced to one honest signal
```gherkin
Given a session with magnet_dropout_pct <= 5
When the report card renders
Then no data-quality card, stat row, or dropout strip appears
Given a session with magnet_dropout_pct > 5
Then exactly one dropout warning strip appears
And no code path anywhere gates display on `warnings.length > 0`
```

## AC-4: Efficiency is banded, not blanked
```gherkin
Given a session with cv_isi > 0.8 in Advanced mode
When MetricGrid renders
Then the efficiency metrics are still shown, with a banner explaining they are unreliable
And no metric is replaced by a blank or a dash on account of that gate
```

## AC-5: Time-to-Distance names its start, and offers the fix
```gherkin
Given a session whose metrics were recomputed from an annotation
When Time to Distance renders
Then it states the start time and that it came from the annotation
Given a session with no annotation
Then it states the start time is auto-detected
And offers a link to /app/annotate/{id} to set it manually
```

## AC-6: Prev/next moves between one athlete's sessions
```gherkin
Given an athlete with three or more sessions, viewing the middle one
When the report card renders
Then controls appear to move to the chronologically adjacent sessions of the SAME athlete
And at the newest session the "newer" control is absent or disabled
And navigating does not lose the current view mode or unit toggle
```
