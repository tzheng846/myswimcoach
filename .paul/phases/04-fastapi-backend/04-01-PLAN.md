<objective>
## Goal
Create a FastAPI server (`api.py`) that exposes `GET /health` and `POST /process`. The process endpoint accepts a raw encoder CSV upload, runs the full signal processing and metrics pipeline, and returns a JSON response containing session metrics, per-cycle data, and the velocity/time arrays needed to render a chart.

## Purpose
Every future component (iOS app, Streamlit cloud, billing middleware) calls this server. It is the foundation of the commercial architecture. The goal is to get it running locally and verifiable with a real raw CSV before any deployment work.

## Output
- `api.py` — FastAPI app in project root (importable alongside existing Python files)
- `requirements.txt` — updated with `fastapi`, `uvicorn[standard]`, `python-multipart`
- `Procfile` — Railway deployment entrypoint
</objective>

<task type="auto">
  <name>Task 1: Create api.py with /health and /process endpoints</name>
  <files>api.py</files>
  <action>
    Create api.py in the project root. It can import vel_acc_extraction and metrics directly (same directory).

    **Imports and app setup:**
    - `from fastapi import FastAPI, File, UploadFile, HTTPException`
    - `from fastapi.middleware.cors import CORSMiddleware`
    - `import tempfile, os, math, numpy as np`
    - `import vel_acc_extraction as vae`
    - `import metrics as m`
    - Create `app = FastAPI()`
    - Add CORSMiddleware: `allow_origins=["*"]`, `allow_methods=["*"]`, `allow_headers=["*"]`

    **`_clean(obj)` helper (module-level):**
    Recursively sanitize a nested dict/list for JSON serialization:
    - `dict` → recurse on values
    - `list` → recurse on items
    - `np.integer` → `int(obj)`
    - `np.floating` or `float` → `None` if nan/inf, else `float(obj)`
    - `np.ndarray` → `_clean(obj.tolist())`
    - Everything else → return as-is

    **`GET /health`:**
    Return `{"status": "ok"}`.

    **`POST /process`:**
    Accept `file: UploadFile = File(...)`.

    Steps:
    1. Write upload bytes to a NamedTemporaryFile (suffix=".csv", delete=False). Record path.
    2. Wrap everything in try/finally; always `os.unlink(raw_path)` in finally.
    3. Call pipeline sub-functions directly (NOT `process_file` — it generates HTML):
       - `df = vae.load_data(raw_path)`
       - `_, angle_unwrapped = vae.unwrap_angle(df)`
       - `dist_m = vae.counts_to_distance(angle_unwrapped, vae.METERS_PER_COUNT)`
       - `t = df["time_s"].values`
       - Infer `native_fs`: `1.0 / np.median(np.diff(t)[np.diff(t) > 0])`
       - `dist_native, _ = vae.interpolate_to_uniform(dist_m, t, native_fs)`
       - `dist_dec, t_dec, actual_fs = vae.decimate_signal(dist_native, native_fs, 100.0)`
       - `t_dec = t_dec + t[0]`
       - `vel = np.gradient(dist_dec, 1.0 / actual_fs)`
       - Coarse accel: decimate vel to 5 Hz, gradient, interpolate back to full rate (same pattern as process_file lines 190–193)
    4. `result = m.compute_session_metrics(t_dec, vel, dist_dec)`
    5. Return:
       ```python
       {
           "session":  _clean(result["session"]),
           "cycles":   _clean(result["cycles"]),
           "time":     _clean(t_dec.tolist()),
           "velocity": _clean(vel.tolist()),
       }
       ```
    6. On any exception inside the try block: `raise HTTPException(status_code=500, detail=str(e))`

    Avoid: calling `process_file` (creates HTML side-effect); calling `plot_results` or `plot_wavelet`; modifying any globals in vel_acc_extraction.
  </action>
  <verify>
    python -c "import api" succeeds with no ImportError.

    curl http://localhost:8000/health returns {"status":"ok"}.
  </verify>
