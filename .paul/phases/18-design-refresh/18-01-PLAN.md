## Design spec (from Swimnetics Screens standalone.html — rendered mockup)

**Screen 01 — Login:**
- Background: #07090E (keep, current is #000 — close enough)
- Wave SVG logo: sinusoidal path ~3 waves, stroke #5B8DEF, width 3, no fill, linecap round
- "SWIMNETICS" in large bold spaced uppercase letters (fontSize 28, letterSpacing 6, fontWeight 700)

**Screen 02 — Athletes:**
- Each athlete card has a 40×40 circle avatar left of the name
- Avatar bg color: deterministic from first letter (use a fixed palette of 6 blue/purple/teal shades)
- Avatar shows first initial of athlete name, white, fontSize 16, fontWeight 700
- Card body: name + stroke type + last session (e.g. "Jun 5 · 31.2 SPM")

- Keep "History ›" link at bottom of card (required for navigation)
- "+ Add Athlete" button at bottom: full-width, matches current dark style
