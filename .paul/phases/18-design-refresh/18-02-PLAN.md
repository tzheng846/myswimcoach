## Goal
Implement design mockup changes for History and Report screens: session cards show RATE/SPEED/DIST in 3 labeled columns with always-visible stroke badge; Report card gains a compact SESSION card (LAP TIME / RATE / SPEED) as the first visible block.

## Purpose
History cards (Screen 05) and Report card (Screen 06) are the two highest-information screens coaches use after every session. The design makes them more scannable.

## Output
- SessionHistoryScreen.js: session card layout matches design — name+date row; star+stroke badge row; 3-col RATE/SPEED/DIST body
- ReportCardScreen.js: SESSION card (LAP TIME / RATE / SPEED) rendered as first card below the header
</objective>

## Design spec (from Swimnetics Screens standalone.html — rendered mockup)

**Screen 05 — History session card:**
- Row 1 (header): name (bold, white) on left | date (muted gray) on left below name
- Row 2 (badges): ★ gold star (if starred) + stroke badge pill always shown
  - Stroke badge shows abbreviated label: Breaststroke→"Breast", Freestyle→"Free", Backstroke→"Back", Butterfly→"Fly", Individual Medley→"IM", Underwater Dolphin Kick→"UDK"
  - Badge style: blue pill (#1E3A5F bg, #7FAACC text) — same as current
- Body: 3 columns only — RATE (SPM) | SPEED (m/s) | DIST (m)
  - Remove Strokes count column (current has 4 columns: Rate/Avg Speed/Distance/Strokes)
  - Column labels uppercase, small gray; values large white; units small gray below

**Screen 06 — Report card SESSION card:**
- Immediately below the header (‹ History | athleteName | ★ | date+name)
- Card labeled "SESSION" (uppercase, small gray label inside card)
- 3 columns: LAP TIME (s) | RATE (SPM) | SPEED (m/s)
- Values from metrics_json.session: lap_time_s, stroke_rate_spm, mean_vel_ms
- This is a NEW card inserted before the existing full metrics section
- The existing full metrics section below it stays unchanged

       ```jsx
       function SessionSummaryCard({ metrics, unit }) {
         const s = metrics?.session ?? {};
         const lapRaw = s.lap_time_s;
         const lapFmt = lapRaw != null
           ? lapRaw >= 60
             ? `${Math.floor(lapRaw / 60)}:${String(Math.round(lapRaw % 60)).padStart(2, '0')}`
             : lapRaw.toFixed(1)
           : '--';
         const rate  = s.stroke_rate_spm?.toFixed(1) ?? '--';
         const speed = s.mean_vel_ms != null
           ? (unit === 'imperial' ? (s.mean_vel_ms * 1.09361).toFixed(2) : s.mean_vel_ms.toFixed(2))
           : '--';
         const speedUnit = unit === 'imperial' ? 'yd/s' : 'm/s';
         return (
           <View style={ssc.card}>
             <Text style={ssc.label}>SESSION</Text>
             <View style={ssc.row}>
               <View style={ssc.col}>
                 <Text style={ssc.colLabel}>LAP TIME</Text>
                 <Text style={ssc.colValue}>{lapFmt}</Text>
                 <Text style={ssc.colUnit}>s</Text>
               </View>
               <View style={ssc.col}>
                 <Text style={ssc.colLabel}>RATE</Text>
                 <Text style={ssc.colValue}>{rate}</Text>
                 <Text style={ssc.colUnit}>SPM</Text>
               </View>
               <View style={ssc.col}>
                 <Text style={ssc.colLabel}>SPEED</Text>
                 <Text style={ssc.colValue}>{speed}</Text>
                 <Text style={ssc.colUnit}>{speedUnit}</Text>
               </View>
             </View>
           </View>
         );
       }
       const ssc = StyleSheet.create({
         card:      { backgroundColor: '#1a1a1a', borderRadius: 10, padding: 16, marginHorizontal: 20, marginBottom: 16 },
         label:     { color: '#555', fontSize: 11, fontWeight: '600', letterSpacing: 1, marginBottom: 12 },
         row:       { flexDirection: 'row' },
         col:       { flex: 1, alignItems: 'center' },
         colLabel:  { color: '#666', fontSize: 10, fontWeight: '600', letterSpacing: 0.5, marginBottom: 4 },
         colValue:  { color: '#fff', fontSize: 22, fontWeight: '700' },
         colUnit:   { color: '#555', fontSize: 11, marginTop: 2 },
       });
       ```
