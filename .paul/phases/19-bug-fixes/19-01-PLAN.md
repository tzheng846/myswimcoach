<task type="auto">
  <name>Task 1: Fix chip shape + swipe behavior in SessionHistoryScreen</name>
  <files>swimnetics-mobile/src/screens/SessionHistoryScreen.js</files>
  <action>
    **Chip shape fix:**
    In the `st` StyleSheet, update `chip` to have an explicit height and a matching border radius so both short ("All") and long ("Breaststroke") labels render as pills:
    ```
    chip: { height: 34, paddingHorizontal: 14, borderRadius: 17, backgroundColor: '#1a1a1a', borderWidth: 1, borderColor: '#333', justifyContent: 'center' }
    ```
    Remove `paddingVertical` (height is now explicit). Add `justifyContent: 'center'` so text stays centered.
    Also add `alignItems: 'center'` to `filterRow` so the FlatList doesn't stretch chips vertically.

    **Swipe — snap fully open on terminated gesture:**
    In `onPanResponderTerminate`, apply the same threshold logic used in `onPanResponderRelease`:
    ```js
    onPanResponderTerminate: (_, g) => {
      const base = isOpen.current ? -ACTION_WIDTH : 0;
      const moved = base + g.dx;
      if (moved < -SWIPE_THRESHOLD) {
        open();
      } else {
        close();
      }
    },
    ```
    Currently it just springs to the previous state without checking the threshold.

    **Swipe — tap on open card closes it:**
    In `onPanResponderRelease`, add an early tap-detection guard before the threshold check:
    ```js
    onPanResponderRelease: (_, g) => {
      // Tap on open card → close
      if (isOpen.current && Math.abs(g.dx) < 5 && Math.abs(g.dy) < 5) {
        close();
        return;
      }
      const base = isOpen.current ? -ACTION_WIDTH : 0;
      const moved = base + g.dx;
      if (moved < -SWIPE_THRESHOLD) {
        open();
      } else {
        close();
      }
    },
    ```
    Without this guard, when open: `moved = -140 < -80` always passes, so `open()` is called every time (tap included) — the card never closes.
  </action>
  <verify>Read the modified file and confirm: chip has height:34 + borderRadius:17; onPanResponderTerminate uses threshold; onPanResponderRelease has the tap guard.</verify>
  <done>AC-1 satisfied: chips have uniform pill shape. AC-2 satisfied: swipe snaps correctly and taps close open cards.</done>
