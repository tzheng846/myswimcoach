<objective>
## Goal
Fine-tune the Swimnetics marketing site: cut the copy down to buyer-facing
benefit language (drop "encoder", "~270 Hz", and similar jargon), move the
interactive velocity chart higher on the page, add a hover tooltip showing the
y-axis (m/s) value, remove the "glide" marker, show a sample value on each
metric card, and replace the wave logo with a text-only "SWIMNETICS" wordmark
everywhere it appears.

## Purpose
The current homepage reads like an engineering spec. Coaches buy outcomes, not
sample rates. Tighter copy + a value-on-each-metric layout + the proof chart
surfaced early makes the page sell. (Marketing polish — supports the v0.5
commercial-foundation goal of a first paying program.)

## Output
Edited marketing components + shared chrome (Nav/Footer), the chart moved up in
`app/page.js`, sample values on the Features metric cards, and the WaveMark
removed from all 5 render sites (component file deleted). No legal-page text
(`/privacy`, `/faq`) is touched.
</objective>
