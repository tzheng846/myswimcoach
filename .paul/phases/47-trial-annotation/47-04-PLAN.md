<objective>
## Goal
Close the annotation → metrics loop: saving an annotation with stroke marks automatically
recomputes the session's metrics through the existing pipeline using the human boundaries
(overwriting `metrics_json`, original auto result backed up once in `metrics_json_auto`;
deleting the annotation restores it), plus a bulk ground-truth export (endpoint + dev script)
for 16-06 segmenter tuning.

## Purpose
This is why annotations exist: (a) corrected metrics flow to every consumer — report card,
pillar ratings, team overview, AI chat — with zero client changes, because they all read
`metrics_json`; (b) hand labels become a machine-readable tuning set for the wavelet
segmenter. Resolves the user-reported 47-02 gap ("saving annotations doesn't update metrics").

## Output
- `metrics.py` — additive optional `manual` overrides in `compute_session_metrics` (default path byte-identical)
- `annotations.py` — `annotation_to_overrides(annotation, n_samples)` (times → indices mapping)
- `api.py` — recompute-on-save in PUT /annotations; DELETE restores auto; GET /annotations/export
- `supabase/patch_08_metrics_backup.sql` — `sessions.metrics_json_auto JSONB` (user-applied)
- `fetch_annotations.py` — dev script saving the export locally for tuning notebooks
- `web/app/app/annotate/[id]/page.js` — saved-message reflects "metrics recomputed"
- Tests extended (suite currently 131)
</objective>

## Decisions (user, 2026-07-12, AskUserQuestion ×4)
- Overwrite + backup: recompute writes metrics_json; original auto result preserved ONCE in metrics_json_auto; all consumers update automatically.
- Trigger: AUTO on annotation save (PUT); no separate endpoint/button.
- FULL phase use: dive_start→baseline_end, stroke_start→initial-phase end, finish→swim end; cycles from stroke marks; per-field fallback to auto-detection when a phase is null.
- Export: GET /annotations/export (auth, coach-scoped) + fetch_annotations.py dev script.

## Index mapping (locked convention)
idx = round(time_s × 100), clamped to [0, len(velocity_profile)−1]. Cycle boundaries =
stroke_marks_s (+ finish_s appended when it exceeds the last mark); cycles = consecutive
boundary pairs → M boundaries yield M−1 cycles; recompute requires ≥2 boundaries.
