<objective>
## Goal
Ship the annotation GUI: a coach-portal page `/app/annotate/[id]` where the user clicks the
velocity trace to place/adjust the five phase boundaries (dive → underwater/pulldown →
breakout → stroke → finish) and individual stroke marks, pre-seeded from the auto-segmenter,
with a synced video pane when a video is attached — saving through the locked 47-01 API.

## Purpose
This is the tool itself: hand-labeling trials against velocity + video produces the ground
truth for 16-06 segmenter tuning and the corrections 47-04 recomputes from. Portal placement
means "later integrated for any user" is already true.

## Output
- `web/app/app/annotate/[id]/page.js` — annotation page (data load, save, layout)
- `web/components/portal/AnnotationChart.js` — click-to-mark velocity chart (recharts)
- `web/components/portal/AnnotationEditor.js` — tool palette + marks state + save UI
- `web/components/portal/VideoPane.js` — upload / signed-URL playback / sync / origin nudge
- `web/lib/api.js` — new `apiUpload` helper (multipart; existing `apiFetch` untouched)
- `web/app/app/sessions/[id]/page.js` — "Annotate" link on the report card
</objective>

- GET  /sessions/{id}/annotations → {annotation|null, seed, video|null, duration_s}
- PUT  /sessions/{id}/annotations   {phases:{dive_start_s,underwater_start_s,breakout_start_s,stroke_start_s,finish_s}, stroke_marks_s:[sorted], source:"manual"} → 422 {errors:[...]} on bad docs
- POST /sessions/{id}/video         multipart file and/or video_origin_s form field
- GET  /sessions/{id}/video-url   → {url (signed, 3600 s), origin_s}
- sessionTime = origin_s + videoTime; velocity time axis = index/100

<acceptance_criteria>

## AC-1: Click-to-mark editing, pre-seeded
```gherkin
Given a session with metrics but no saved annotation
When the coach opens /app/annotate/[id]
Then the chart shows the seeded draft marks (phases colored + labeled, stroke marks thin dashed)
And selecting a phase tool then clicking the trace places/moves that phase boundary at the clicked time
And the stroke tool adds a mark per click; each mark is removable (chip list × / clear-all)
And "Reset to auto" restores the seed
```

## AC-2: Save round-trip
```gherkin
Given edited marks
When the coach clicks Save
Then the doc PUTs to /sessions/{id}/annotations, the unsaved-changes indicator clears,
And a reload shows the saved annotation (not the seed)
And a backend 422 shows the errors list inline without losing the editor state
```

## AC-3: Video pane with sync (optional per session)
```gherkin
Given a session with an attached video
When the video plays
Then a playhead line moves across the velocity chart at origin_s + currentTime
And the Seek tool (click on trace) jumps the video to t − origin_s (clamped)
And ±0.1 s origin nudge buttons shift the alignment and persist via POST video (origin-only)
Given a session with NO video
Then the editor is fully functional and an "Attach video" file input can upload one (then the pane appears)
```

## AC-4: Portal integration
```gherkin
Given the session report card page
When the coach clicks "Annotate"
Then /app/annotate/[id] opens for that session, and its back link returns to the report card
And `npm run build` stays green
```
