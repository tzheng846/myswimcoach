## Goal
Add BLE recording to the iOS app: scan for SwimLogger, connect, record a session (streaming Nordic UART packets), stop, and save a raw CSV to on-device storage. Coach can record a swim without any laptop.

- `package.json` — react-native-ble-plx + buffer added

  <action>
    **Step A — Install packages:**
    Run from `swimnetics-mobile/`:
    ```
    npm install react-native-ble-plx buffer
    ```
    `react-native-ble-plx` pods are auto-discovered by the Podfile's `use_native_modules!` — no manual Podfile editing needed.
    `buffer` provides `Buffer.from()` for base64 decoding in React Native (where Node's Buffer global is absent).

    **Step B — Create `src/screens/RecordScreen.js`:**

    Module-level constants:
    ```javascript
    const NUS_SERVICE  = '6E400001-B5A3-F393-E0A9-E50E24DCCA9E';
    const NUS_TX_CHAR  = '6E400003-B5A3-F393-E0A9-E50E24DCCA9E'; // device → phone (notify)
    const NUS_RX_CHAR  = '6E400002-B5A3-F393-E0A9-E50E24DCCA9E'; // phone → device (write)
    const DEVICE_NAME  = 'SwimLogger';
    ```

    Create a single `BleManager` instance at module level (not inside the component):
    ```javascript
    const manager = new BleManager();
    ```

    State variables (useState):
    - `bleState`: 'idle' | 'scanning' | 'connecting' | 'connected' | 'recording' | 'saving' | 'done' | 'error'
    - `devices`: array of `{ id, name }` (found during scan)
    - `sampleCount`: number
    - `savedPath`: string | null
    - `errorMsg`: string | null

    Refs (useRef — not state, to avoid re-renders):
    - `deviceRef` — the connected BleDevice
    - `subscriptionRef` — the characteristic monitor subscription (for cleanup)
    - `samplesRef` — `[]` array that accumulates `{timestamp_us, angle_counts, magnet_ok}` objects

    **`parsePacket(base64)` helper function:**
    ```javascript
    function parsePacket(base64) {
      const buf = Buffer.from(base64, 'base64');
      if (buf.length !== 14) return [];
      return [0, 7].map(offset => ({
        timestamp_us: buf.readUInt32LE(offset),
        angle_counts: buf.readUInt16LE(offset + 4),
        magnet_ok: buf.readUInt8(offset + 6),
      }));
    }
    ```

    **`startScan()` function:**
    - Set state 'scanning'
    - Clear `devices` state to `[]`
    - `manager.startDeviceScan(null, null, (error, device) => { ... })`
    - In callback: if error → set state 'error', errorMsg; return
    - If device.name === DEVICE_NAME and not already in list → add to `devices`
    - `manager.stopDeviceScan()` after 8 seconds via `setTimeout`
    - Set state 'idle' (back to device list) after scan stops

    **`connectTo(deviceId)` function:**
    - `manager.stopDeviceScan()`
    - Set state 'connecting'
    - `const device = await manager.connectToDevice(deviceId)`
    - `await device.discoverAllServicesAndCharacteristics()`
    - `deviceRef.current = device`
    - Set state 'connected'
    - On error: set state 'error', errorMsg

    **`startRecording()` function:**
    - Reset `samplesRef.current = []`, `setSampleCount(0)`
    - Write START command: `await deviceRef.current.writeCharacteristicWithoutResponseForService(NUS_SERVICE, NUS_RX_CHAR, Buffer.from('START\n').toString('base64'))`
    - Subscribe: `subscriptionRef.current = deviceRef.current.monitorCharacteristicForService(NUS_SERVICE, NUS_TX_CHAR, onData)`
    - Set state 'recording'
    - Handle device disconnect: `deviceRef.current.onDisconnected((error) => { ... set error state, save partial CSV ... })`

    **`onData(error, characteristic)` callback:**
    - If error → call `stopRecording(true)` (partial save)
    - Parse: `const samples = parsePacket(characteristic.value)`
    - `samplesRef.current.push(...samples)`
    - `setSampleCount(c => c + samples.length)` (batched setState)

    **`stopRecording(isError = false)` function:**
    - `subscriptionRef.current?.remove()`
    - Try: `await deviceRef.current?.writeCharacteristicWithoutResponseForService(NUS_SERVICE, NUS_RX_CHAR, Buffer.from('STOP\n').toString('base64'))`
    - Set state 'saving'
    - Build CSV string:
      ```javascript
      const header = 'timestamp_us,angle_counts,magnet_ok\n';
      const rows = samplesRef.current.map(s => `${s.timestamp_us},${s.angle_counts},${s.magnet_ok}`).join('\n');
      ```
    - Filename: `session_${Date.now()}.csv`
    - `await FileSystem.writeAsStringAsync(FileSystem.documentDirectory + filename, header + rows)`
    - Set `savedPath`, set state isError ? 'error' : 'done'

    **UI (JSX):**
    Render one section based on `bleState`:
    - `idle` / after scan: "Scan for Devices" button + FlatList of found devices (tap to connect)
    - `scanning`: ActivityIndicator + "Scanning..."
    - `connecting`: ActivityIndicator + "Connecting..."
    - `connected`: "SwimLogger connected" + "Start Recording" button
    - `recording`: sample counter + "Stop Recording" button (red)
    - `saving`: ActivityIndicator + "Saving..."
    - `done`: "✓ Saved {sampleCount} samples" + filename + "Record Again" button
    - `error`: error message + "Try Again" button

    Avoid:
    - Creating BleManager inside the component (creates multiple instances)
    - Calling setState inside the BLE callback synchronously on every sample (batch via ref + periodic update)
    - Forgetting to call `subscriptionRef.current?.remove()` on cleanup (useEffect return)

    **Step C — Update `App.js`:**
    Replace the default scaffold content with:
    ```javascript
    import RecordScreen from './src/screens/RecordScreen';
    export default function App() {
      return <RecordScreen />;
    }
    ```
    Add a SafeAreaView wrapper if needed for status bar clearance.

    **Step D — Create `src/` directory and commit:**
    ```
    mkdir swimnetics-mobile/src
    mkdir swimnetics-mobile/src/screens
    ```
    Then git add + commit from `swimnetics-mobile/`.
