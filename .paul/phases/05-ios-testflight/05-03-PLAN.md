<objective>
## Goal
After a session is saved, automatically upload the raw CSV to FastAPI `/process`, receive metrics JSON, and display a velocity chart + 4 headline metrics on screen. Coach sees results within 30 seconds of tapping Stop.

## Purpose
This closes the full loop: BLE record → process → display. Without results on screen, the app is a data collector with no coaching value. This is the payoff of the entire Phase 5.

## Output
- `src/config.js` — API_BASE URL constant (easy to update after Railway deploy)
- `src/screens/RecordScreen.js` — extended with `uploading` + `results` states, upload function, velocity chart, headline metrics
- `package.json` — react-native-svg added
</objective>

    **`uploadAndProcess(filePath)` async function (add before startScan):**
    ```javascript
    const uploadAndProcess = useCallback(async (filePath) => {
      log(`Uploading ${filePath.split('/').pop()} to ${API_BASE}...`);
      setBleState('uploading');

      try {
        const formData = new FormData();
        formData.append('file', {
          uri: filePath,
          name: filePath.split('/').pop(),
          type: 'text/csv',
        });

        const response = await fetch(`${API_BASE}/process`, {
          method: 'POST',
          body: formData,
          // Do NOT set Content-Type manually — fetch sets it with the boundary
        });

        if (!response.ok) {
          const text = await response.text();
          throw new Error(`API ${response.status}: ${text.slice(0, 120)}`);
        }

        const data = await response.json();
        log(`Upload complete. Stroke rate: ${data.session?.stroke_rate_spm?.toFixed(1)} SPM`, 'ok');
        setApiResult(data);
        setBleState('results');
      } catch (e) {
        log(`Upload failed: ${e.message}`, 'error');
        setBleState('error');
      }
    }, [log]);
    ```

    **`VelocityChart` component (add before the main component):**
    Accepts `time` (number[]) and `velocity` (number[]) props.

    - Chart dimensions: width = `Dimensions.get('window').width - 48`, height = 160
    - Normalize: `x = (t - tMin) / (tMax - tMin) * width`, `y = height - (v - vMin) / (vMax - vMin) * height`
    - Build points string: `"x0,y0 x1,y1 ..."`
    - Render:
      ```jsx
      <Svg width={width} height={height + 24} style={{ marginTop: 8 }}>
        {/* zero-velocity baseline */}
        <Line x1={0} y1={zeroY} x2={width} y2={zeroY} stroke="#E0E0E0" strokeWidth={1} />
        {/* velocity line */}
        <Polyline points={points} fill="none" stroke="#1E3A5F" strokeWidth={1.5} />
        {/* axis labels */}
        <SvgText x={0} y={height + 18} fontSize={10} fill="#999">{tMin.toFixed(0)}s</SvgText>
        <SvgText x={width - 20} y={height + 18} fontSize={10} fill="#999">{tMax.toFixed(0)}s</SvgText>

      </Svg>
      ```
