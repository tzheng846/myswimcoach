<objective>
## Goal
Make individual **stroke cycles** visible on the Swimming section inset: one alternating
blue/purple band per cycle from `metrics_json.cycles`, neutral grey everywhere else, a boundary tick
at every band edge, a count badge carrying human-vs-auto provenance, a per-band hover readout, and
bidirectional cross-highlight with the four `CycleCharts` panels — plus an amber outline on the
duration-outlier cycle.

**Frontend only. Zero backend.** `metrics_json.cycles` already exists on every session and
`PUT /annotations` already replaces it with the coach's cycles, so CONTEXT D12's
"annotations first, auto fallback" is satisfied by reading the stored array — no precedence code.

## Purpose
Every per-cycle number the report card shows is derived from boundaries the chart never draws, so a
coach cannot audit segmentation by eye. This is also the cheap half of Phase 83: it ships against
existing data and **derisks the shared banding component** that 83-02 reuses for kicks.

## Output
- New pure lib `web/lib/cycleBands.js` (bands + outlier, no React)
- `PhaseVelocity` gains an optional `bands` prop → multi-color segments, ticks, hover regions
- `PhaseReportCard` wires the Swimming inset, badge, and lifted hover state
- `CycleCharts` / `TrendPanel` gain optional highlight props (additive — `CompareCycleCharts` untouched)
- New additive theme tokens
</objective>

    - `items` is `metrics_json.cycles` (83-02 will pass kicks through the same function — keep the

    - Drop entries with non-finite or missing `start_idx`/`end_idx`, and entries where

    - `n` is 1-based and assigned AFTER filtering, so it matches `CycleCharts`' `n: i + 1` only when

      `cycle_num + 1` when present, else the pre-filter array position + 1 — so the cross-highlight
      key stays aligned with the charts even if a band was dropped.
    - `outlier`: index of max |duration − median(duration)| across the surviving bands, using the
      duration key; `false` on every other band. Require **≥3 bands** to flag anything (with 1–2 the
      "furthest from median" is meaningless). Ignore non-finite durations; if fewer than 3 remain
